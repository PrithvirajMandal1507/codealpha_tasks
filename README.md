This repository contains my C programming tasks completed as part of the CodeAlpha C Programming Internship.

## Tasks Completed

### 1. Simple Calculator
A menu-driven calculator supporting:
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Division/modulus by zero validation

**File:** `calculator.c`

### 2. Matrix Operations
A matrix program supporting:
- Matrix input
- Matrix display
- Matrix addition
- Matrix multiplication
- Matrix transpose
- Matrix size validation
- Menu-driven repeated execution

**File:** `matrix_program.c`

### 3. Student Management System
A file-based student management system supporting:
- Add student
- Delete student
- Update student
- Search student
- Display all students
- Duplicate record checking
- Class validation (1–12)
- Positive roll-number validation
- Input validation
- File handling using binary files

**File:** `student_management.c`
